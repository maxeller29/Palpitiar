01

O que é o Claude Code

O Claude Code é a versão do Claude projetada para rodar diretamente no terminal, com acesso completo ao sistema de arquivos, execução de comandos e integração com ferramentas de desenvolvimento. Diferente do claude.ai, ele não apenas conversa — ele age.

Funcionalidade claude.ai (Web) Claude Code (Terminal)
Lê seus arquivos✗ Precisa colar✓ Acesso direto
Edita código✗ Só sugere✓ Salva no disco
Executa comandos✗ Não✓ npm, python, git...
Memória do projeto✗ Limitada✓ CLAUDE.md persistente
Artefatos visuais✓ Cards, SVG, HTML✗ Não
Custo adicionalIncluso no ProIncluso no Pro
🔧

Acesso direto ao código

Lê todos os arquivos do projeto sem copiar/colar. Entende imports, dependências e estrutura de pastas.

⚡

Executa e corrige

Roda scripts, vê o output e corrige erros em loop — até funcionar.

🧠

Contexto persistente

Com CLAUDE.md, ele lembra como seu projeto funciona entre sessões.

💰

Incluso no Pro

Sem custo extra de API. Usa o mesmo plano Claude Pro que você já paga.

02

Instalação e Configuração

Pré-requisitos

  • Node.js v18 ou superior instalado
  • VS Code instalado com terminal integrado
  • Conta Claude Pro (maxeller@gmail.com)

Instalar o Claude Code

powershell
npm install -g @anthropic-ai/claude-code

Autenticação

Na primeira execução, o Claude Code abre o browser automaticamente para login com sua conta Anthropic. Após isso, fica autenticado permanentemente.

powershell
claude
# Abre o browser para login na primeira vez

Abrindo no VS Code

  1. Abra a pasta do projeto no VS Code (File › Open Folder)
  2. Abra o terminal integrado: Ctrl+`
  3. Navegue para a pasta do projeto se necessário
  4. Digite claude e pressione Enter

Interface e Navegação

Como interagir

O prompt fica no rodapé da tela. Digite em linguagem natural — português funciona perfeitamente:

exemplos
› analise a estrutura deste projeto
› crie um script Python que lê o arquivo historico.json
› corrija os erros de TypeScript no arquivo gerador.js
› faça commit das mudanças com a mensagem "fix: ajuste no gerador"

Confirmações de segurança

Antes de editar arquivos ou executar comandos, o Claude Code sempre pede confirmação:

Terminal — confirmação
• Write(gerador.js)

Do you want to overwrite gerador.js?
› 1. Yes
2. Yes, allow all edits during this session (Shift+Tab)
3. No
⚠️ Ao usar a opção 2 (allow all edits), o Claude editará arquivos sem perguntar pelo resto da sessão. Use somente quando confiar na tarefa em andamento.

07

Múltiplas Tarefas em Paralelo

Às vezes é necessário fazer outra coisa enquanto o Claude trabalha. Três opções:

Opção A — Novo terminal (recomendado)

Clique no + na barra de terminais ou use Ctrl+Shift+\ para abrir um terminal PowerShell normal ao lado. O Claude Code continua rodando no dele — você usa o outro para git, node, python etc.

Opção B — Duas sessões Claude Code

No novo terminal, digite claude novamente. Duas sessões independentes rodam simultaneamente.

⚠️ Duas sessões editando os mesmos arquivos ao mesmo tempo pode gerar conflito. Use para projetos ou pastas diferentes.

Opção C — Interromper e retomar

  • Ctrl+C para pausar o que está fazendo
  • Digite o novo comando ou pergunta
  • O contexto anterior permanece na memória da sessão
💡 Para o projeto Loterias: Claude Code no terminal dele + terminal PowerShell ao lado para git e npm é a configuração ideal.

09

CLAUDE.md — Memória do Projeto

O CLAUDE.md é o arquivo mais importante para uso avançado. Ele funciona como memória persistente — toda sessão iniciada na pasta do projeto, o Claude lê esse arquivo automaticamente.

O que colocar

  • Visão geral do projeto (o que é, para que serve)
  • Comandos principais (npm run, python scripts/...)
  • Arquitetura de pastas e arquivos importantes
  • Convenções e regras do projeto
  • Restrições e armadilhas conhecidas

Exemplo — Projeto Palpitiar

CLAUDE.md
## Regras do Projeto

- NUNCA mostrar dezenas nos cards sociais (preserva funil do site)
- Cores por loteria: seguir paleta oficial da Caixa Econômica
- Stack: HTML/CSS/JS puro — sem build step
- Deploy: Netlify (arquivos estáticos diretos)
- Banco: Supabase (anon key exposta é intencional)
- API Caixa: CORS — usar workaround via proxy
- SVG deve ser convertido para PNG via cairosvg antes do Instagram

## Comandos

npm run gerar-artigos     # gera artigos do blog (requer ANTHROPIC_API_KEY)
node scripts/atualizar-historico.js  # atualiza JSONs das loterias

Como atualizar via Claude Code

claude
› adiciona no CLAUDE.md que o SVG deve ser convertido
  para PNG via cairosvg antes de publicar no Instagram
💡 Mantenha o CLAUDE.md atualizado com as decisões do projeto. É o que garante consistência entre sessões diferentes — sem precisar reexplicar tudo do zero.
10

Boas Práticas

Seja específico

Quanto mais contexto, melhor o resultado:

comparação
❌ › arruma o código

✅ › o arquivo scripts/gerador.js está retornando undefined
      na linha 47 quando o JSON da Caixa vem vazio — corrija
      sem quebrar o fallback que já existe na linha 83

Revise antes de confirmar

O Claude mostra um diff no VS Code antes de salvar. Leia com atenção ao editar arquivos críticos como index.html ou scripts de deploy.

Use Ctrl+C sem medo

Se perceber que está indo na direção errada, interrompa. O contexto fica salvo, você reexplica e ele recomeça.

Faça git commit antes de mudanças grandes

Assim você pode reverter com git checkout se necessário. O Claude pode editar muitos arquivos de uma vez.

Tarefas longas com muitos arquivosClaude Code no VS Code
11

Limitações e Cuidados

O que o Claude Code não faz

  • Não acessa a internet por conta própria (exceto com /chrome ativo)
  • Não tem memória entre sessões — só o CLAUDE.md persiste
  • Não gera imagens ou SVGs (use o claude.ai para isso)
  • Não executa código em sandbox isolado como o claude.ai
⚠️ Nunca use "allow all edits" em projetos em produção sem saber o que será feito. O Claude é capaz de sobrescrever arquivos importantes. Faça um git commit antes de tarefas grandes.

Quando o Claude Code trava ou erra

recuperação

Ctrl+C

# 2. Limpar contexto
› /clear

# 3. Reexplicar de forma diferente

Verificar consumo

Em sessões longas, use /cost periodicamente para saber quanto de token foi consumido.
